# Card Creator

A React + TypeScript + Vite app for laying out collector cards on an A4 page.

Live site: https://zprima.github.io/cardcreator/

## Prerequisites

- [Node.js](https://nodejs.org/) (current LTS recommended)
- npm (comes with Node.js)

## Run locally

Install dependencies, then start the Vite dev server:

```bash
npm install
npm run dev
```

The app is served at [http://localhost:5173](http://localhost:5173). The page reloads when you edit source files.

## Build

Create a production build:

```bash
npm run build
```

This type-checks the project, then writes optimized static files to `dist/`.

## Run the build

Preview the production build locally:

```bash
npm run preview
```

This serves the contents of `dist/` (run `npm run build` first). By default it is available at [http://localhost:4173](http://localhost:4173).
